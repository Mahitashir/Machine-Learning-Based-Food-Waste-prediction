# Machine-Learning-Based-Food-Waste-prediction
Many kitchen whether it is commercial or institutional they face problems many challenges due to overproduction of food. This create a load of food waste. This study develops a ML supervised model like Linear Regression, Decision Trees and Neural Network to predict food_waste_kg .
This study develops a ML supervised model like Linear Regression,
Decision Trees and Neural Network to predict food_waste_kg based on features
like kitchen_staff, staff_experience, meal_served, temperature_C,
humidity_percent, waste_category, special_event and also past_waste_kg. We
preprocessed through the pipeline to handle missing values, scale numerical
features and encode categorical data. Cross Validation shows us that the models
has achieved the better r2 when they use crossValidation . Later we also divided
the dataset into 3 clusters using Kmeans.
